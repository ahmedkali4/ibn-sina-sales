# منظومة ابن سينا - بوابة المبيعات وصفحة الهبوط ولوحة الإدارة والتراخيص
**Ibn Sina Medical Clinic System - Sales Hub, Admin Dashboard & Landing Page**

بوابة متكاملة لمبيعات وإدارة تراخيص **منظومة ابن سينا لإدارة العيادات والمراكز الطبية**، مصممة للنشر المباشر السلس على **GitHub** و **Vercel** وتعمل محلياً وسحابياً.

---

### 🌟 أهم مميزات المنظومة:

1. **حل مشكلة احتساب زيارات المدير (Option 1):**
   - تم تطبيق عزل ذكي مزدوج (عبر الجلسة Backend و Cookie/localStorage في Frontend).
   - عند دخول المالك/المدير لصفحة الهبوط أو لوحة الإدارة، يتم كتم وتعطيل تسجيل الزيارة تماماً بحيث تظل إحصائيات الزوار نقية 100% وتعبر عن الأطباء والعملاء الحقيقيين فقط.
   - شريط إداري سري يظهر فقط للمدير عند تصفح صفحة الهبوط يتيح له التنقل السريع للوحة التحكم أو التحويل لزائر عادي.

2. **صفحة هبوط تسويقية طبية احترافية عالية التحويل (High-Converting Landing Page):**
   - هوية بصرية طبية مصرية حديثة (كحلي ملكي + تركواز + زمردي).
   - استعراض بنك الأدوية المصري الشامل (25,133 دواء ببدائلها ومادتها الفعالة).
   - محرك فحص التعارضات والحساسية الدوائية الفوري.
   - حاسبة توفير تفاعلية للعيادات والمراكز.
   - نموذج حجز واستشارة مجانية للأطباء (Lead Capture Form).
   - زر تحميل تجريبي مباشر وتواصل واتساب بنقرة واحدة.

3. **لوحة إدارة ومتابعة العملاء (Medical CRM & Dashboard):**
   - إحصائيات الزوار الحقيقيين، معدل التحويل، ومرات التحميل.
   - إدارة طلبات واستفسارات الأطباء (Leads) مع تغيير الحالة بنقرة واحدة.
   - محادثة واتساب فورية مجهزة برسائل ترحيبية طبية مخصصة بالاسم.

4. **مولد التراخيص الطبية المعتمدة (License Key Generator):**
   - متوافق بنسبة 100% مع محرك التراخيص المشفر `clinic/licensing.py` باستخدام خوارزميات التوقيع الرقمي (Ed25519 / HMAC-SHA256).
   - إصدار تراخيص دائمة، سنوية، نصف سنوية، أو تجريبية بكود الجهاز (Machine ID).
   - مشاركة كود التفعيل ورسالة التوجيهات للطبيب على واتساب بنقرة زر واحدة.

5. **الإدارة المالية وإيصالات القبض المطبوعة:**
   - متابعة الدفعات النقدية والمقدمات والأقساط ومستحقات المناديب.
   - طباعة إيصالات قبض وسداد مالية رسمية منسقة بضغطة زر.

6. **رادار الأجهزة والبيكون الصامت (Telemetry Radar):**
   - استقبال نبضات تشغيل النسخ التجريبية من أجهزة العيادات لمتابعة فترة الـ 7 أيام والتواصل مع الطبيب قبل انتهائها.

### ☁️ خطوات النشر على GitHub و Vercel:

1. **تهيئة Git والرفع على GitHub:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Al Tabeeb Medical Sales Hub & Landing"
   git branch -M main
   git remote add origin https://github.com/<your-username>/al-tabeeb-sales.git
   git push -u origin main
   ```

2. **النشر على Vercel:**
   - ادخل على حسابك في [Vercel](https://vercel.com).
   - اضغط **Add New Project** واختر المستودع `al-tabeeb-sales`.
   - اترك إعدادات Framework Preset كـ **Other**.
   - اضغط **Deploy**.
   - مبروك! سيعمل المشروع فوراً مع دعم Serverless Python عبر `api/index.py` و `vercel.json`.
